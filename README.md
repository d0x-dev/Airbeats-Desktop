## 🚀 Installation Guide

### 🐧 Linux (Recommended)
Airbeats is officially available on the Canonical Snap Store for all major Linux distributions! To install, simply run this single command in your terminal:

```bash
sudo snap install airbeats
```
*Alternatively, you can download the `.AppImage` or `.deb` files from the table above.*

### 🪟 Windows
1. Download the latest `.exe` from the table above.
2. Double-click the installer and follow the prompt.
3. Airbeats will automatically install and add a shortcut to your Desktop!

### 🍎 macOS
1. Download the latest `.dmg` from the table above.
2. Double-click the `.dmg` file to open it.
3. Drag the Airbeats icon into your **Applications** folder.

## 🛠️ Build from Source

Ready to build AirBeats Desktop yourself? Follow our comprehensive guide below.

### Prerequisites

| Requirement | Version |
|------------|---------|
| **Node.js** | 20+ |
| **Python** | 3.13 |
| **Git** | Latest |

### 🚀 Build Steps

```bash
# 1. Clone the repository
git clone https://github.com/d0x-dev/Airbeats-Desktop.git

# 2. Navigate into the project
cd Airbeats-Desktop

# 3. Create a python virtual environment
python -m venv venv
venv\Scriptsctivate
pip install -r requirements.txt

# 4. Navigate to the electron wrapper
cd electron-app

# 5. Install Node dependencies
npm install

# 6. Build the Executable
npm run build
```
